# ARC-164 PCBs

**Last updated: November 3, 2026 at 4:54 AM MST (America/Denver)**

I’m developing the current PCB designs. No PCB design files are currently published.

## Control layout

I’m using **rotary encoders for all five frequency controls**, with rotary switches for MAIN and PRESET and encoders for VOL and channel. I’ve restored my original encoder project locally and still need to check the layout, clearances, wiring, and test fit before publishing the updated boards.

**I won’t offer an ARC-164 version with frequency rotary switches**, because fitting them would require cutting or enlarging the holes in the clear underpanel and cutting anti-rotation alignment slots for the switches. Future versions will keep frequency encoders. See the [current frequency-control plan](../README.md#frequency-controls).
